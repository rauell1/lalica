# Logo and imagery manifest

All assets below were extracted from the unmodified source PDF
`Lalica Company Profile_.pdf` using PyMuPDF at the PDF's native raster
resolution. Nothing is AI generated, upscaled past the source resolution,
or redrawn. File names record the physical PDF page and the extraction
coordinates in points.

The PDF's logo drawing is the only logo artwork in the source document. It
is a raster drawing, not vector artwork. Do not describe vector versions as
the original logo. Rights are assumed to belong to Lalica Engineering
Limited as the company's own profile document; record any confirmation in
docs/content-verification.md.

## Rights notes

- The partner brand marks on PDF page 10 are trademarks of their
  respective owners. They are extracted for reference only. They must not
  be published on the site unless each brand's logo use is confirmed and
  permitted. See docs/content-verification.md.
- The source PDF is kept byte for byte unchanged. All extraction happened
  from a read-only copy so the original remains the authoritative source.
- Re-encoding (JPEG to PNG and the logo to JPEG) is lossless in the sense
  that no scaling or editing was applied; JPEG re-encoding of an already
  lossy source is noted and accepted for web use.
